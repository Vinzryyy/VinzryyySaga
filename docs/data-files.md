# Data Armeniaca: di mana, isinya apa, siapa yang mengubah

The same map is shown on the admin hub (`/admin/<kunci rahasia>`, page
`src/pages/AdminHub.jsx`, data `src/data/adminData.js`). Keep the two in sync
by editing `src/data/adminData.js`; this file is the readable copy.

## Labels

| Label | Meaning |
|---|---|
| Ditulis tangan | Edit freely, on GitHub or locally |
| Bot otomatis | Rewritten by a GitHub Actions bot; hand edits are overwritten |
| EliRecorder | Published from EliRecorder on the Mac; edit there |
| Dibuat script | Output of a script in `scripts/`; change the source and re-run |

## Changing the admin hub key

The key is never stored in this public repo, only its SHA-256 in
`ADMIN_KEY_HASH` (`src/pages/AdminHub.jsx`). To replace it:

```bash
node -e "const c=require('crypto');const k=c.randomBytes(18).toString('base64url');console.log('link: /admin/'+k);console.log('hash:',c.createHash('sha256').update(k).digest('hex'))"
```

Put the new hash in `ADMIN_KEY_HASH`, commit, and keep the link somewhere
private. A wrong key shows the normal 404 page.
